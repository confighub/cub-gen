# cub-gen v0.3.0

Released: 2026-04-12
Previous release: `v0.2-preview.2` (2026-04-11)

## Summary

`v0.3.0` is the first non-preview `cub-gen` release. It keeps the repo-first
CLI shape from the preview line and closes the last large Helm depth gaps that
were still open at the end of `v0.2-preview.2`.

## Highlights

1. Repo-first CLI is stable and easier to use.
   - local-first commands default `<render-target-path>` to `<target-path>`
   - help/docs/examples all teach the same start path
   - the change surface now includes `preview`, `run`, `diff`,
     `revision-diff`, `impact`, and `explain`

2. Helm provenance is much more honest.
   - `change explain` now calls out CLI overrides, built-ins, helper chains,
     render-time non-deterministic sources, and external refs instead of
     pretending every field came from a normal values file

3. Release-note and forward-reasoning flows are real CLI features.
   - `change diff`, `change revision-diff`, and `change impact` now provide
     field-level before/after provenance and DRY-to-WET change pairing

4. Generator chaining is first-class for declared pipelines.
   - Score -> Helm style chains now show up directly in `detect`,
     `gitops discover`, and `gitops import`
   - `change explain` preserves chained hops back to upstream DRY inputs

5. The shipped generator surface now includes 9 first-class families.
   - that includes standalone `applicationset` support alongside Helm, Score,
     Spring Boot, Backstage, no-config-platform, ops-workflow, c3agent, and
     Swamp

6. Flagship examples are in a stronger product state.
   - Helm, Score, Spring, and Swamp all have clearer entrypoints, explicit AI
     bundles, governed-proof paths, and honest connected/live proof boundaries
